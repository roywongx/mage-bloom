# 11 · 小六月 1.3.4 数据审计（客户端实测对照）

> 审计时间：2026-11-20。对象：LiuyueForever 1.3.4（NewBeeBox mod 35224，file id 724742）。
> 证据来源：① 插件包逆向；② 客户端只读探针（构建 `1.60.1.70959`，角色约 36 级）；③ NewBeeBox 公开版本接口。

## 1. 版本线：没有更新的版本可升

NewBeeBox `POST /v3/mod_file/mod_file_list`（`mod_id=35224, game_version_id=9`）返回全部 3 个版本：

| 版本 | 发布时间 | 大小 | changelog |
| --- | --- | --- | --- |
| 1.3.1 | 2026-11-11 15:41 | 12,813,196 | 全职业初步适配，测试版 01 |
| 1.3.3 | 2026-11-12 03:33 | 12,824,033 | 修复手柄绑定（Xbox360）；修复 DoT 检测导致的重复施法 |
| **1.3.4** | **2026-11-12 09:13** | **12,843,788** | 大部分职业输出循环优化，适配 1-60 级 |

`addon_version.txt` 内容 `724742` 与接口 `t_id` 完全一致，确认安装的就是最新版。

**结论**：上游没有可升版本。所谓“升级”只能是：
1. 等作者更新（不可控）；
2. 在它之上做增强层（本项目 M1）；
3. 直接改它的数据文件（会被下一次更新覆盖，不推荐）。

## 2. 插件数据审计

### 2.1 SpellBook：自定义技能只留了最高 rank

`Core/SpellBook.lua` 法师 35 条，但自定义技能 ID 列表不完整：

| 技能 | 小六月 | 客户端/其他数据源 | 影响 |
| --- | --- | --- | --- |
| 冰枪术 | `{1240047}` 1 个 | 6 个 rank：1312002/400640/1240044/1240045/1240046/1240047 | 低等级解析可能失败 |
| 奥术冲击 | `{1239700}` 1 个 | 5 个 rank：400574/1239696/1239697/1239699/1239700 | 36 级角色实际用 1239696 |
| 奥术愤怒 | `{1326082}` 1 个 | 4 个 rank：1326079/1326080/1326081/1326082 | 36 级角色实际用 1326080 |
| 霜火之箭 | 3 个 rank | 3 个 rank | 正常 |

这与运行时“按名称 → `GetSpellInfo` 取当前 rank”的路径不冲突，但说明它的 ID 表不是“客户端全量”，而是**只保留一个兜底 ID**。

### 2.3 APL：四套表，法师最多 8 条，且没有触发条件

| 表 | 用途 | 法师规则数 | 问题 |
| --- | --- | --- | --- |
| `APLData.GEN` | 通用/兜底 | 8 / 7 / 5 | 有 AOE，但无触发、无法力 |
| `APL.DATA` | 主表 | 3 / 2 / 3 | 过薄 |
| `LEVELING_SPEC_CHAINS` | 练级 | 4 / 4 / 4 | 无寒冰指、无热力迸发 |
| `EXTRA` | 备用/纯输出 | 4 / 5 / 5 | 有保命，无触发 |

引擎条件集里**没有**“buff 存在且层数 ≥N”“buff 剩余 <N”“正在施放某技能”，所以即使作者知道机制，也写不出来。

### 2.4 VoiceData：混入大量非无限服技能

法师语音表包含 `冰冷血脉`、`召唤水元素`、`深度冻结`、`奥术弹幕`、`镜像`、`活动炸弹`、`思维冷却`、`龙息术`、`减速`、`专注魔法`。这些是 TBC/WotLK 技能，无限服法师表里不存在（客户端探针未解析到，SpellBook 也没有）。说明该表是**跨版本遗留**，不是按本客户端清洗过的。

### 2.5 天赋预设：只有 60 级

`TalentData.MAGE` 5 套预设全部 `level = 60`，36 级角色只能靠实时读取天赋树点数判断专精。

## 3. 客户端实测（只读探针）

### 3.1 环境

- `GetBuildInfo()`：`1.60.1` / `70959` / `Nov 13 2026` / Interface `16001`
- 角色：约 36 级法师（已学寒冰箭 8407、奥术飞弹 8416、火球 8400、奥术冲击 1239696、奥术愤怒 1326080、暴风雪 8427、魔甲术 6117）
- 已挂增益：奥术智慧 1461、霜甲术 7301、精神饱满 429959

### 3.3 等级适配

角色约 36 级，意味着：
- 不能假设 60 级技能全会（冰枪、寒冰护体、炎爆、燃烧、霜火都未学）；
- 规则必须 **按名称解析当前 rank**，未学会自动跳过；
- 练级期的主力是：寒冰箭 / 火球 / 灼烧 / 火焰冲击 / 奥术冲击 / 奥术飞弹 / 奥术愤怒 / 暴风雪 / 魔爆术 / 冰锥术 / 冰霜新星；
- 触发（热力迸发、飞弹连射）在 30+ 级已可出现，必须支持。

## 4. 对 MageBloom 的结论

1. **继续采用伴生模式**：小六月的执行层（安全信道、按钮、专精识别）可用，策略层整体替换。
2. **数据以客户端实测为准**：优先级为 客户端探针 > WowSims APL > ForeverDB > 小六月表。
3. **APL 必须等级自适应**：按名称解析、未学跳过；60 级规则与练级规则分开。
4. **触发 ID 用双候选**：寒冰指 400669/400670；火焰易伤待实测，暂不写死。
5. **不直接改小六月文件**：避免更新覆盖；增强层独立发布。
