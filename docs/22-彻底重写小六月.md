# 22 · 路线变更：彻底重写小六月（Fork / Rewrite）

> 2026-11-20 用户拍板：**不再做 companion、不再做独立探针。**
> 以 `LiuyueForever 1.3.4` 为基座 fork/rewrite，对外仍叫 `LiuyueForever`（伪装），
> 朋友只装这一份，里面就是我们的 MageBloom。

## 1. 结论

| 旧路线 | 新路线 |
| --- | --- |
| MageBloom 作为小六月伴生插件 | **直接改小六月本体** |
| 独立 `MageCtl` / `wowcap/state.py` 状态层 | 复用 `LF.AuraState` / `LF.SpellBook` / `LF.Talents` / `LF.Ledger` |
| 独立收集器 `MageProbe` / `LiuyueHook` | 本体内的 `Core/MageBloom.lua` 导出 `MageBloomDB` |
| 对外两个 addon | 对外只有一个 `LiuyueForever` |

## 2. 保留什么

- `Engine/Smart.lua`：安全按钮、宽度信道、编译、绑定。
- `Core/AuraState.lua`：光环层数/剩余/DoT 保护/secret 处理。
- `Core/SpellBook.lua` / `SpellIdCandidates`：名称→当前 rank、学习等级。
- `Core/SpellDuration.lua` / `SpellAlias` / `SpellIdByName`：持续期、别名。
- `Core/Talents.lua` / `TalentData`：专精、天赋。
- `Core/Ledger.lua` / `TTD.lua` / `FailWatch`：资源、预计死亡、失败冷却。
- `Core/APL.lua` / `AplString.lua`：规则解释器、导入导出。
- `TitanForever` 的 128×12 控制块（Windows 侧位姿/目标/flags）。

## 3. 替换什么

- 法师 APL：三系（冰/火/奥）完整规则，触发/层数/AOE/移动/法力/打断。
- 决策：接管 `LF.APL.EffectiveChain` / `LF.APL.PickIndex`（仅 MAGE）。
- 数据导出：`Core/MageBloom.lua` 写 `MageBloomDB`。
- 不再注册 `COMBAT_LOG_EVENT_UNFILTERED`；不读敌方光环（除 Liuyue 自己的安全 Query）；不碰 secret value。

## 5. 模块职责

- `MB.DATA`：三系规则（`spell/target/cd/buff/debuff/debuffBelow/aoe/moving/notChanneling/...`）。
- `MB.Pick`：用 `LF.AuraState.Query` 做 buff 层数/剩余，用 `LF.APL.Resolve` 过滤未学技能。
- `MB.Chain`：返回当前专精链，供 `LF.Smart.Compile` 编译。
- `MB.Export`：`MageBloomDB` = 法术书、持续期、天赋、APL、配置、自身光环、构建号。
- `/mb dump`：手动导出；`/reload` 落盘。

## 6. 分发

- 整包 `LiuyueForever`（含素材/语音）重新打包；朋友不需要另装小六月。
- 安装脚本：
  1. 备份原版 `LiuyueForever` 到 `%LOCALAPPDATA%\MageBloomCollector\backup\`；
  2. 移走旧 `MageProbe` / `MageData` / `LiuyueHook`（含备份）；
  3. 复制改版 `LiuyueForever`。
- 打包脚本收集 `SavedVariables\MageBloomDB.lua` + `LiuyueForeverDB.lua`。

## 7. 开发规则

1. 不再新增 companion/独立 state 层；所有读数据走 Liuyue。
2. `windows/wowctl` 保留为 Windows 单次控制 CLI（W0），不属于数据层。
3. `windows/wowcap/state.py` 停止扩展；若保留，只做 Liuyue/TitanForever 的适配。
4. 任何改动必须能通过：无游戏不启动、没有 assist 不发键、状态过期不动作。
5. 不注册 CLEU、不读敌方光环、不碰 secret value；否则会被客户端禁用。

## 9. 风险

- 客户端可能把“战斗插件”整体限制；先保证不触发 CLEU/secret。
- 原版更新会覆盖 fork；每次上游更新要重新打补丁（保留 `Core/MageBloom.lua`）。
- 整包 13–19 MB；分发走 zip，不入 git。
