# ADR 0003 · Profile 是数据，不是代码

- 状态：接受
- 日期：2026-11-20

## 背景

小六月的 `APL.lua` 有 320 KB，规则、解析、诊断、职业特判混在一起；新增一条规则要改代码、无法单独测试、无法版本化。

## 决策

- 规则用声明式表（Lua/JSON），字段见 [03 APL 规范](../03-APL规范.md)；
- 引擎只解释规则，不认识任何具体技能；
- 每个 profile 带 `schema`、`game_build`、`source`、`changelog`；
- CI 校验 schema 与技能可解析性。

## 后果

- 正向：新增专精只写数据；规则可审阅、可 diff、可回滚；社区可贡献。
- 负向：极端特殊机制（形态、连击点）需要扩展条件集，不能写魔法代码。
- 缓解：条件集按需求扩展，保持正交；禁止在引擎里写 `if spell == "寒冰箭"`。

## 备选

1. 规则即 Lua 函数：灵活但不可校验、不可自动对比。
2. 引入 DSL 编译器：过度设计，首版不需要。
