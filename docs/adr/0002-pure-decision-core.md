# ADR 0002 · 决策核心是纯函数

- 状态：接受
- 日期：2026-11-20

## 背景

一键插件的 bug 往往表现为"偶尔放错技能"，无法复现。根因是决策与游戏状态、UI、施法副作用耦合。

## 决策

`Decide(state, profile, config) -> Decision` 必须是纯函数：

- 不调用写 API；
- 不读全局可变状态（除常量表）；
- 不产生副作用；
- 输出包含完整 trace。

State 由 `Observe` 每 tick 构建为不可变快照。

## 后果

- 正向：可用 fixture 离线复现任意决策；可用属性测试扫边界；parity 可自动化。
- 负向：每 tick 需要构建快照（性能预算 0.25 ms）；状态字段需精心设计。
- 缓解：快照复用表、按需查询、10 Hz 节流。

## 备选

1. 就地读 API 的 `if/else`：无法测试，否决。
2. 事件驱动增量状态：复杂度高，收益不足以抵消风险。
