# ADR 0005 · 多步预测默认关闭

- 状态：接受
- 日期：2026-11-20

## 背景

Hekili 的核心是向前模拟若干步。但预测依赖对伤害、暴击、触发概率的建模；在无限服缺少可靠系数时，错误预测会把优先级带偏。

## 决策

首版只做**优先级 + guard**（确定性、可解释）。M2 引入 2 步轻量投影，仅用于：

- 队列显示（下一个、下下个）；
- 同分候选的排序；

默认 `lookahead = 0`，玩家可在配置中开到 2。首条命中语义不变。

## 后果

- 正向：行为可预测；容易与 WowSims APL 对比；出问题能定位到具体规则。
- 负向：不做预测时，个别"提前铺垫"的收益拿不到（如为下一发炎爆留层）。
- 缓解：用规则显式表达铺垫（如奥冲层数条件），而不是靠预测。

## 备选

1. 首版就做 3–5 步模拟：需要伤害系数与概率模型，数据不足。
2. 永远不做预测：队列体验差，且无法处理"下一发更优"的取舍。
