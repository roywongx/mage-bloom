# ADR 0004 · 不依赖 WeakAuras

- 状态：接受
- 日期：2026-11-20

## 背景

虚空之花以 WA 字符串分发，生态成熟；但 WA 字符串不可审阅、难测试、与版本强绑定，且其目标是泰坦重铸 3.80，不是无限 1.60。

## 决策

本项目不依赖 WeakAuras。可选导入 `LYF1.` 字符串作为兼容层，但不把 WA 作为运行时依赖。

## 后果

- 正向：可独立测试；无 WA 版本兼容问题；性能可控；源码可审阅。
- 负向：失去 WA 生态的现成策略与用户习惯。
- 缓解：提供 APL 导入/导出；文档说明与 WA 的差异；M4 可考虑可选桥接。

## 备选

1. 直接生成 WA 字符串：受 WA API 限制，无法做状态与 trace。
2. 同时维护两套：维护成本翻倍。
