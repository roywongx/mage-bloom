# ADR 0001 · 先做伴生模式，再做独立核心

- 状态：接受
- 日期：2026-11-20

## 背景

小六月 1.3.4 已实现安全派发、一键按钮、专精识别与按键生态。我们真正要改的是**决策层**。如果一开始就重写执行层，会把 80% 的时间花在复现已有能力上，且无法快速拿到实机对比数据。

## 决策

M1/M2 采用伴生模式：作为独立插件加载，运行时接管 `EffectiveChain` / `PickIndex`（仅法师），复用其按钮与安全信道。M3 再替换为独立核心。

## 后果

- 正向：一周内可上线；可直接 A/B 原版；风险低；不改上游文件。
- 负向：受上游版本影响；两套配置并存；需要版本探测与降级。
- 缓解：hook 失败自动只读；`/mb off` 一键回滚；M3 保留同一套 core。

## 备选

1. 直接 fork 小六月源码：受混淆与体积拖累，且升级即冲突。
2. 完全独立重写：执行层风险高，验证周期长。
