# 04 · 安全派发通道

> 目标：在**战斗锁定**下，根据实时状态把"下一次该放的技能"交给安全按钮执行，且不触发污染、不违反一次按键一次动作的边界。

## 1. 问题

WoW 的战斗锁定（`InCombatLockdown()`）禁止非安全代码：

- 修改安全帧的 `type` / `spell` / `macrotext` 等属性；
- 创建/销毁安全帧、改绑定；
- 调用 `CastSpellByName` 等受保护函数。

而"一键循环"必须在战斗中不断切换下一个技能。唯一合法路径是：**点击瞬间，在受限环境（restricted environment）里完成属性设置**，再由安全按钮自身执行施法。

小六月 1.3.4 找到了一条可行通道；我们保留其思想并工程化。

## 2. 机制

### 2.1 三个角色

| 角色 | 类型 | 作用 |
| --- | --- | --- |
| 安全按钮 `B` | `SecureActionButtonTemplate, SecureHandlerBaseTemplate` | 接收点击，执行 `type/spell/unit` |
| 数据通道 `Td` | 隐藏 `GameTooltip` + `SecureFrameTemplate` | 用左内边距宽度编码"决策索引" |
| 提交通道 `Tk` | 同上 | 与 `Td` 写同一宽度，用于"提交确认" |

### 2.2 编码

- 索引 `i ∈ [0, N]`，`0` 表示"无推荐"。
- 左内边距 `pad(i) = BASE + i × STEP`，`STEP = 8 px`。
- 两个 tooltip 都 `SetPadding(pad(i), 0, 0, 0)`，保持 `Show()` 且 `alpha = 0`。
- 载入时**标定**：对每个 `i` 写入 padding，读取 `GetWidth()`，记录 `width[i]`；要求相邻宽度差 ≥ 2 px，否则增大 `STEP` 或降低 `N`。

### 2.3 提交与校验

`SetPadding` 可能被客户端钳制（最小/最大宽度、UI scale 变化）。因此：

1. 写入后读回 `Td:GetWidth()`；
2. 与标定值比较，偏差 > 1.5 px → 重试（最多 5 次，间隔 50 ms）；
3. 点击时要求 `|width(Td) − width(Tk)| ≤ 0.5`，否则视为"未提交"，本次点击不施法。

### 2.4 点击瞬间

```lua
SecureHandlerWrapScript(B, "OnClick", B, snippet)
```

`snippet` 在受限环境执行，`self` 即按钮：

```lua
self:SetAttribute("type", nil)          -- 先清空，未命中则不施法
local d = self:GetFrameRef("sd")
local k = self:GetFrameRef("sk")
if not d or not k then return end
local wd = d:GetWidth()
local wk = k:GetWidth()
if not wd or not wk then return end
if wd < W0_LO or wd > W0_HI then return end
if wk < W0_LO or wk > W0_HI then return end
if wd >= W_A_LO and wd <= W_A_HI and wk >= W_A_LO and wk <= W_A_HI then
    self:SetAttribute("type", "spell")
    self:SetAttribute("spell", "冰枪术")
    self:SetAttribute("unit", "target")
    return
end
-- 其余索引同理
```

约束：

- 受限环境只保证少量全局函数；**不使用 `math.abs`/`rawtype`**，用区间比较代替；
- 字符串需转义 `\` 与 `"`；
- 代码长度随规则数线性增长，上限 16 条（与小六月一致），超出则截断并告警；
- 每次点击只设置一次属性，随后安全按钮原生逻辑执行，**不循环、不延迟、不重试**。

### 2.5 时序

```
tick(100ms)            click(用户)               受保护执行
────────────────────────────────────────────────────────────
Observe → Decide
        → SetPadding(Td, Tk)
        → 读回校验
                          OnClick 前置 snippet
                            ├─ 读宽度
                            ├─ 匹配索引
                            ├─ SetAttribute(type/spell/unit)
                            └─ return
                                              安全按钮施法
```

决策索引在两次 tick 之间可能变化；每次变化都重写 padding。点击使用**点击时刻**已写入的值，因此不存在"读到旧决策"的窗口（写入是同步的）。

## 3. 约束与误差

| 约束 | 影响 | 处理 |
| --- | --- | --- |
| 宽度量化 | 索引可能难以区分 | STEP=8 px，标定校验，必要时降 N |
| UI scale 改变 | 标定值失效 | 监听 `UI_SCALE_CHANGED`，脱战重标定 |
| tooltip 被钳制 | 宽度不随 padding 变 | 读回比对，失败则降级 |
| 战斗中不能重建 | 规则变更需等待 | 排队到 `PLAYER_REGEN_ENABLED` |
| 受限环境语法 | 不能调用任意 API | 只用比较、`GetFrameRef`、`SetAttribute` |
| 规则数上限 | 每系最多 16 个不同技能 | profile 校验时强制 |

## 4. 失效检测与降级

| 检测 | 判定 | 降级 |
| --- | --- | --- |
| `SecureHandlerWrapScript` 不存在 | 客户端/模板不支持 | 静态模式：仅脱战设置技能，提示"动态派发不可用" |
| 标定宽度重复 | 通道不可用 | 增大 STEP 重标定一次；仍失败则静态模式 |
| 读回宽度不变 | padding 被忽略 | 重试 5 次；失败则静态模式 |
| 双通道不一致 | 提交未生效 | 本次点击不施法，trace 记录 |
| 规则数 > 16 | 编译截断 | 告警并保留前 16 条（按优先级） |

降级永远**不施法**比**施错法**安全。

## 5. 替代方案与取舍

| 方案 | 原理 | 问题 | 结论 |
| --- | --- | --- | --- |
| `RegisterStateDriver` + 宏条件 | 状态驱动宏条件 | 只能表达内置条件（姿态/坐骑/战斗），无法表达层数/触发 | 仅用于姿态类 |
| 动作条翻页 | 预置多页按钮 | 页数有限、切换受保护 | 不可行 |
| `/click` 扇出 | 多个隐藏按钮各绑一技能，按索引点击 | 仍需动态选择点哪个；跨帧调用受保护 | 不如宽度通道 |
| `CastSpellByName` | 直接施法 | 战斗中受保护 | 不可行 |
| 本条通道 | 点击瞬间在受限环境改属性 | 依赖宽度量化与模板 | **采用** |

## 6. 安全与合规边界

- **一次按键 = 一次动作**：插件不在定时器里施法，不在 tick 里施法，不模拟按键。
- **不读隐藏信息**：只用 `UnitAura`/`UnitCastingInfo`/`GetSpellCooldown` 等公开 API。
- **不注入、不修改客户端**：无 DLL、无内存读写、无封包。
- **可关闭**：`/mb off` 立即恢复小六月原生行为。
- **可见**：`/mb test` 输出决策与跳过原因。
